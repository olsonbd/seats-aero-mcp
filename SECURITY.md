# Security policy

## Supported versions

Security fixes are made on the latest release and the `main` branch. Upgrade to the latest release before reporting an issue that may already be fixed.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/olsonbd/seats-aero-mcp/security/advisories/new). Do not open a public issue for a suspected vulnerability.

Never include a Seats.aero API key, MCP bearer token, private endpoint, personal travel data, or complete upstream response. If a credential may have been exposed, revoke or rotate it immediately before submitting the report.

Include the affected version, transport, impact, minimal reproduction, and any sanitized logs. You should receive an initial response within seven days. Please allow time for a fix before public disclosure.
